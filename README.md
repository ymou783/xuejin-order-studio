# 雪烬电竞 · 订单小票工坊

一个可直接部署的订单与服务房间网页，使用 Node.js 提供网页和接口，使用 SQLite 保存订单、服务记录、陪陪修改记录、结单评价和房间目录。

## 页面入口

- `index.html`：订单小票工坊
- `xuejin-ops-center-260808.html`：房间后台入口
- `room.html?orderId=...`：独立服务房间
- `settlement.html?orderId=...`：结单小票

## 直接运行

项目不需要腾讯云账号、数据库账号、密钥或额外配置。服务器安装 Node.js 22.13 或更高版本后，在项目目录执行：

```bash
npm start
```

默认访问地址：`http://服务器地址:3000`

首次启动会自动创建 `data/xuejin.sqlite`，数据库表结构位于 `schema.sql`。SQLite 文件就是项目的持久化数据，可以定期备份整个 `data` 目录。

如需使用其他端口，可以临时设置 `PORT` 环境变量；不设置时使用 3000 端口。

## 数据同步

浏览器页面通过同源 HTTP 接口读写 SQLite，服务端通过实时连接把房间变化推送给其他浏览器。多个用户打开相同订单号的房间链接时，可以实时看到该房间的保底、战绩、陪陪和结单状态变化。

服务房间、结单页面、后台目录和带订单号的小票页面都支持实时刷新。服务器不可用时，浏览器会保留本地数据，恢复服务器后可继续使用；首次切换到 SQL 版本时，已有的本地订单会自动补入数据库中。

## 部署建议

1. 将项目目录上传到服务器。
2. 安装 Node.js 22.5 或更高版本。
3. 在项目目录执行 `npm start`，或使用进程管理器保持服务运行。
4. 将服务器的 3000 端口映射到域名或反向代理。

当前项目没有用户登录，知道链接的用户可以访问对应订单。后台密码仍然属于网页端校验，只适合内部工具；如果要面向公网使用，下一步应增加真正的用户登录和权限控制。
