# 雪烬电竞 · 订单小票工坊

一个基于订单号唯一 key 的静态订单与服务管理网页，包含：

- 订单通知解析与订单小票生成
- 生成小票时自动创建独立服务房间
- 保底、撤离率、服务操作和陪陪修改记录
- 结单评价与结单小票 PNG 保存
- 房间后台、网页链接、日志查看、日志清理和房间管理

## 页面入口

- `index.html`：订单小票工坊
- `admin.html`：房间后台
- `room.html?orderId=...`：独立服务房间
- `settlement.html?orderId=...`：结单小票

数据默认保存在浏览器的 localStorage 中。GitHub Pages 负责托管网页文件；不同设备或不同浏览器之间不会自动同步房间数据。
